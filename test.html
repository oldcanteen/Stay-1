Extension local test

How to run
From the folder that contains this file, start a local server, for example:
python -m http.server 8765
Then open http://127.0.0.1:8765/test.html
Reload the unpacked extension in chrome://extensions after changing manifest.json. In DevTools → Console, filter for [CWG] to see load / timer / popup logs.
